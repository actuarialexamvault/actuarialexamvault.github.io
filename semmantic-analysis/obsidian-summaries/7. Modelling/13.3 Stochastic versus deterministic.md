
> [!danger] Stochastic vs deterministic
> A **stochastic** approach may be preferred, because:
>- we need to find the cost of guarantees and options
>- we would wish to see the likely distribution of outcomes, not just a single estimate
>- the interaction between variables can be explicitly included, enabling the effect of the interactions to be assessed
>- we need to estimate a probability.
>
>**Deterministic** modelling can be used:
>- with sensitivity testing, in order to get an approximation to a stochastic result
>- where the result obtained would be very similar to (or, if not, more prudent than) a stochastically produced result
>- as a check on a stochastic model.
>
>Stochastic models suffer from high sensitivity to the chosen parameter values, with the risk of [[../../Definitions/Spurious accuracy]]. So we should only use stochastic modelling when the variable can be reliably modelled by a well-defined probability distribution.
